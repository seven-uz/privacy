O'zbekcha

BirgaPlay — sport maydonlarini band qilish platformasi. Ilova ishlashi uchun akkaunt va telefon raqam bilan ro'yxatdan o'tish talab qilinadi (boshqa ilovalardan farqli — bu ilova oflayn emas, server bilan ishlaydi).

Yig'iladigan ma'lumotlar: telefon raqami (autentifikatsiya), ism, band qilish tarixi, wallet/cashback balansi, jamoa va o'yin ma'lumotlari, joylashuv (maydon qidirish uchun, agar ruxsat berilsa).

Saqlash: ma'lumotlar BirgaPlay serverida (production joylashtirilgach — hosting ma'lumoti shu yerga qo'shiladi) saqlanadi.

Uchinchi tomonlar: to'lov provayderi (agar ulansa) va xarita xizmati (OpenStreetMap) bilan ishlash mumkin — aniq ro'yxat production integratsiyalari tasdiqlangach yangilanadi.

Aloqa: uzseven.uz@gmail.com

English

BirgaPlay is a sports venue booking platform. Using the app requires account sign-up with a phone number (unlike offline apps — this one relies on a backend server).

Data collected: phone number (authentication), name, booking history, wallet/cashback balance, team and game data, location (for venue search, if permission is granted).

Storage: data is stored on the BirgaPlay server (hosting details will be added once production infrastructure is deployed).

Third parties: a payment provider (if integrated) and a mapping service (OpenStreetMap) may be used — the exact list will be finalized once production integrations are confirmed.

## Umumiy shablon

Barcha sahifalar `assets/style.css` + `assets/theme.js`dan foydalanadi (yagona zamonaviy
dizayn, light/dark mavzu, responsiv). Yangi ilova qo'shishda mavjud papkalardan birini
namuna qilib oling — `<style>` blokini takrorlamang, faqat `<link rel="stylesheet"
href="/assets/style.css" />` qo'shing.

## GitHub Pages

Repo **private** bo'lgani uchun GitHub'ning bepul rejasi Pages'ni qo'llab-quvvatlamaydi
(`Settings → Pages` sozlamasi reja cheklovi tufayli o'chib qolgan bo'lishi mumkin — shu
sabab yangi push'lar qayta build bo'lmay qolgan). Pages ishlashi uchun repo **public**
bo'lishi yoki GitHub Pro/Team rejasi kerak. Bu sahifalar (maxfiylik siyosatlari) tabiatan
ochiq/ommaviy matn bo'lgani uchun repo'ni public qilish tavsiya etiladi.

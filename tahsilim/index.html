O'zbekcha

1. Umumiy ma'lumot

Tahsilim — o'zbek tilida so'zlashuvchilar uchun arab tilini o'rganish platformasi (darslar, mashqlar, lug'at, audio). Ilova tahsilim.uz serveri bilan ishlaydi, shuning uchun o'quv jarayonini saqlash uchun akkaunt kerak bo'ladi.

2. Qanday ma'lumot to'planadi

Quyidagilar faqat qurilmangizda saqlanadi:

  • kirish tokeni (JWT) — Android Keystore bilan himoyalangan xavfsiz xotirada
  • oflayn ishlash uchun yuklab olingan dars va lug'at nusxasi (lokal SQLite)
  • sozlamalar — interfeys tili, mavzu, audio afzalliklari

Quyidagilar serverga yuboriladi va u yerda saqlanadi:

  • hisob ma'lumotlari — e-pochta manzili va ism (ro'yxatdan o'tishda o'zingiz kiritasiz)
  • parol — faqat qaytarib bo'lmaydigan hash ko'rinishida (asl parol saqlanmaydi)
  • o'quv progressi — tugallangan darslar, mashq natijalari, ballar va seriya (streak)
  • texnik so'rov jurnali (log) — so'rov vaqti va IP manzil, faqat xavfsizlik va nosozlikni aniqlash uchun

Ilova to'plamaydi: joylashuvingiz, kontaktlar ro'yxati, qo'ng'iroq/SMS, kamera yoki mikrofon yozuvlari, reklama identifikatori (Advertising ID), moliyaviy rekvizitlar.

3. Ma'lumot qayerda saqlanadi

Server ma'lumotlari Germaniyadagi (Hetzner, Falkenstein) shaxsiy serverimizda, PostgreSQL bazasida saqlanadi. Serverga faqat administrator kira oladi. Qurilmangizdagi nusxa esa ilovaning xususiy sandbox sohasida turadi.

4. Ma'lumot nima uchun ishlatiladi

To'plangan ma'lumot faqat quyidagi maqsadlarda ishlatiladi:

  • hisobingizga kirish va o'quv progressingizni qurilmalar orasida saqlash;
  • darslar, mashqlar va audio materiallarni yetkazib berish;
  • statistika, grafik va tendensiyalarni qurilmangizning o'zida hisoblash;
  • xizmat xavfsizligini ta'minlash va texnik nosozliklarni aniqlash.

5. Ma'lumot kim bilan ulashiladi

Ma'lumotlaringiz uchinchi tomon kompaniyalariga berilmaydi va sotilmaydi. Ular faqat bizning serverimizda qayta ishlanadi. Reklama tarmoqlari, ma'lumot brokerlari yoki analitika kompaniyalari bilan hech qanday almashinuv yo'q. Qonun talab qilgan hollardagina rasmiy so'rovga javob berishimiz mumkin.

Ilovada reklama yo'q, analitika/kuzatuv SDK'lari yo'q (Firebase Analytics, Google AdMob, Facebook SDK va shu kabilar ishlatilmaydi) va foydalanuvchi profilini tuzish yoki uni uchinchi tomonga sotish amalga oshirilmaydi.

6. Tarmoq va tashqi xizmatlar

Русский

1. Общие сведения

Tahsilim — платформа изучения арабского языка для узбекоязычных пользователей (уроки, упражнения, словарь, аудио). Приложение работает с сервером tahsilim.uz, поэтому для сохранения прогресса требуется аккаунт.

2. Какие данные собираются

Перечисленное ниже хранится только на вашем устройстве:

  • токен доступа (JWT) — в защищённом хранилище Android Keystore
  • локальная копия загруженных уроков и словаря для офлайн-работы (SQLite)
  • настройки — язык интерфейса, тема, аудиопредпочтения

Перечисленное ниже передаётся на сервер и хранится там:

  • данные аккаунта — адрес электронной почты и имя (вы вводите их при регистрации)
  • пароль — только в виде необратимого хеша (исходный пароль не хранится)
  • учебный прогресс — пройденные уроки, результаты упражнений, баллы и серия
  • технический журнал запросов — время запроса и IP-адрес, только для безопасности и диагностики

Приложение не собирает: местоположение, список контактов, звонки/SMS, записи камеры или микрофона, рекламный идентификатор, платёжные реквизиты.

3. Где хранятся данные

Серверные данные хранятся на нашем собственном сервере в Германии (Hetzner, Falkenstein), в базе PostgreSQL. Доступ к серверу есть только у администратора. Локальная копия хранится в приватной песочнице приложения.

4. Для чего используются данные

Собранные данные используются исключительно в следующих целях:

  • вход в аккаунт и сохранение учебного прогресса между устройствами;
  • доставка уроков, упражнений и аудиоматериалов;
  • расчёт статистики, графиков и трендов непосредственно на вашем устройстве;
  • обеспечение безопасности сервиса и диагностика технических сбоев.

English

1. Overview

Tahsilim is an Arabic learning platform for Uzbek speakers (lessons, exercises, dictionary, audio). The app works with the tahsilim.uz server, so an account is needed to save your progress.

2. What data is collected

The following is stored only on your device:

  • access token (JWT) — in Android Keystore-backed secure storage
  • a local copy of downloaded lessons and dictionary for offline use (SQLite)
  • settings — interface language, theme, audio preferences

The following is sent to and stored on our server:

  • account details — e-mail address and name (which you enter at sign-up)
  • password — only as an irreversible hash (never in plain text)
  • learning progress — completed lessons, exercise results, points and streak
  • technical request logs — request time and IP address, solely for security and troubleshooting

The app does not collect: your location, contact list, calls/SMS, camera or microphone recordings, advertising ID, or payment details.

3. Where data is stored

Server data is stored on our own server in Germany (Hetzner, Falkenstein) in a PostgreSQL database. Only the administrator can access the server. The local copy stays in the app's private sandbox.

4. Why the data is used

The collected data is used only for the following purposes:

  • signing you in and keeping your learning progress across devices;
  • delivering lessons, exercises and audio materials;
  • computing statistics, charts and trends directly on your device;
  • keeping the service secure and diagnosing technical problems.

5. Who the data is shared with

Your data is never shared with third-party companies and never sold. It is processed only on our own server. There is no exchange with ad networks, data brokers or analytics companies. Disclosure is possible only in response to a lawful official request.

The app contains no advertising and no analytics/tracking SDKs (no Firebase Analytics, Google AdMob, Facebook SDK or similar). We do not profile users and never sell data to third parties.

6. Network and third-party services

The app connects to the following external services:

  • api.tahsilim.uz — the app's own backend — authentication, lessons and progress. All traffic is HTTPS-encrypted.
